# X2D II 开机工作室

Mac 应用，用于管理 Hasselblad X2D II 100C 的主屏开机图与后续动画。已针对一台固件 1.3.16.2、此前手工改装过的相机核对文件哈希；首次安装到未改装相机、其他相机及恢复流程尚未实机验收。应用检查机型和关键文件哈希，不匹配时停止写入。

## 功能

- 静态开机图：原厂白 H、内置飞思 PHASE ONE、自选 PNG/JPEG。自选图按比例置于黑底，转换成相机使用的 1024×768 NV12 图像。恢复原厂图时使用本机相机自己的备份。
- 动画：可开关，可选择新的 MP4/MOV/M4V，也可保留当前视频。开启后在静态图之后播放；白 H 阶段不会被动画覆盖。首次开启动画必须提供视频。
- 方案预设：保存开机图、动画开关和视频。所选图片与视频会复制到用户的 Application Support，原始文件移走后预设仍可使用；开启动画的预设须选择视频。
- “检查相机”只读取机型、配置和开机图哈希；“应用到相机”会修改相机的系统启动配置和/或 `/factory_data/logo.bin`，并读回校验。固件版本号不变。

## 使用

需要 macOS 13 或更新版本、Apple Silicon、本机 `/usr/bin/python3`、`ffmpeg` 和 `ffprobe`。相机保持开机并接 USB，在相机上选择“大容量存储”。Mac 可能要求管理员授权以建立 USB 诊断连接。先备份照片并保证电量充足。打开应用后先按“检查相机”，选好静态图与动画，再按“应用到相机”；彻底关机再开机检查效果。

“关闭动画”会恢复经校验的原厂启动配置，静态开机图选择独立保留；再次开启会恢复已保存的动画启动配置。对这台此前手工改装的相机，程序识别其原有的启动配置备份。若相机的文件和已验证版本不一致，程序不会尝试猜测或强行写入。USB 诊断不可用时无法使用应用，也无法通过应用恢复。

USB 重新枚举时，macOS 可能再次请求管理员授权。动画开关会在无回执时重新连接、读回相机文件；只有确认启动配置仍是原状才重试一次。如果窗口提示“无法确认写入结果”，请重新接线后先按“检查相机”，不要连续点击“应用”。

## 构建与分发

在此目录执行 `sh build.sh`，输出 `dist/X2D II 开机工作室.app`。App 为临时签名，尚未公证；其他 Mac 可能需要按系统提示确认打开。`rndis-up` 的 MIT 许可文本单独保存在 `THIRD_PARTY_NOTICES.txt`；本项目尚未选择开源许可。源码不含厂商原厂固件或其他设备备份。这是实验性发布；尚需在另一台未改装相机上完成首次安装、冷启动和恢复测试。
